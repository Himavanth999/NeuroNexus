
# Web Development Form – Responsive User Information Form

## 📄 Overview

This is a **responsive and modern HTML-based web form** created as part of a web development assignment or project. The form is designed to collect user information such as name, contact details, address, company, department, and gender. It demonstrates practical use of HTML and CSS for structuring and styling an interactive form.

## 🌟 Features

- ✅ Clean and modern UI with **minimalistic design**
- 📱 Fully **responsive layout** using Flexbox
- 🛡️ HTML5 built-in validation using `required` attributes
- 🖌️ Styled with **pure CSS** (no frameworks)
- 👤 Collects personal and professional information
- 🎨 Smooth hover effects on buttons for better user experience
- 
## 🧩 Form Fields

1. **Full Name** - Text input
2. **Contact Number** - Telephone input
3. **Address** - Multiline text area
4. **Company Name** - Text input
5. **Email Address** - Email input (validates format)
6. **Department** - Dropdown with options (HR, Sales, Development, Marketing, Others)
7. **Gender** - Radio buttons (Male, Female, Prefer not to say)

## 🎯 How to Use

1. Clone or download the repository.
2. Open `index.html` in any modern web browser.
3. Fill out the form fields.
4. Click **Submit** to see how validations work (backend not implemented).
